# 网页 demo

用户确认新增网页，并将 SHA1 `3f9a7c2e1b8d4f6a0c5e9d2b7a4f1c8e6d3b0a5f` 用作设计随机种子。

页面采用编辑部任务板布局。种子的前八位通过取模选中钴蓝方案。页面使用雾紫 #eeedf5、纸白 #fafafc、钴蓝 #3549cf、墨蓝 #24284b、黄色 #f0d362 和灰紫 #76788b。中文标题采用系统宋体，操作区域采用系统无衬线字体。

页面让任务板成为主要视觉元素。预算票据和结果预览采用不同结构，避免所有内容都变成相同卡片。页面在窄屏上改成单列。

本机服务只绑定 127.0.0.1。网页支持历史案例回放、离线流程和真实 API 三种明确标记的体验。真实调用需要本地 .env，网页不读取或显示密钥。业务工具仍使用本地合成数据。运行期间页面展示等待状态，完成后显示实际 Trace，不伪造实时进度。

运行命令：`.venv/Scripts/python.exe -m content_agent.web`。浏览器地址为 `http://127.0.0.1:8765`。网页为新任务生成请求 ID，并在同一标签页内保存。相同输入再次提交或刷新页面会复用该 ID。用户修改输入、切换模式或点击“新建任务”时，网页会创建新 ID。服务端按 ID 和输入指纹返回已有结果或输入冲突。用户关闭标签页后，浏览器可能清除这份临时记录。


开发者需要从源码仓库根目录启动可编辑安装的网页服务。独立 wheel 的验证范围是 CLI 和核心逻辑，wheel 没有捆绑网页资源或历史案例。
